# 画像ファイルについて（集い処 よっちゃん家 デモ）

写真はまだ用意していないため、現時点ではこのフォルダに画像を配置していません。
サイト側は下記のファイル名を参照する実装になっているため、実際の写真が決まったら
同じファイル名でこのフォルダに配置するだけで、仮画像プレースホルダーから自動的に
実写に切り替わります（サイトの他の修正は不要です）。

推奨形式: JPG / 横長カットは 4:3〜16:9 目安。

| ファイル名 | 用途 | 内容の目安 |
|---|---|---|
| `hero.jpg` | トップ ヒーロー背景 | 店内・雰囲気が伝わるカット |
| `interior.jpg` | 店舗紹介セクション | 店内の雰囲気 |
| `menu-1.jpg` | お品書き（仮）1枚目 | 刺身・鮮魚のイメージ |
| `menu-2.jpg` | お品書き（仮）2枚目 | 串焼き・炉端焼きのイメージ |
| `menu-3.jpg` | お品書き（仮）3枚目 | 一品料理・お通しのイメージ |

画像が用意されるまでは、サイト上に「仮画像」バッジと説明文つきのプレースホルダーが表示されます。
掲載する料理写真・内容はすべて提案用の仮表示であり、実際のお品書きとは異なります。

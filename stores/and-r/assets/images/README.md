# 画像ファイルについて（あんどあーる デモ）

写真はまだ用意していないため、現時点ではこのフォルダに画像を配置していません。
サイト側は下記のファイル名を参照する実装になっているため、実際の写真が決まったら
同じファイル名でこのフォルダに配置するだけで、仮画像プレースホルダーから自動的に
実写に切り替わります（サイトの他の修正は不要です）。

推奨形式: JPG / 横長カットは 4:3〜16:9 目安。

| ファイル名 | 用途 | 内容の目安 |
|---|---|---|
| `hero.jpg` | トップ ヒーロー背景 | 店内・スタイルの雰囲気が伝わるカット |
| `menu-photo.jpg` | メニュー「成人式前撮り」 | 前撮りのイメージ |
| `menu-kimono.jpg` | メニュー「着付けセット」 | 着付けのイメージ |
| `menu-cut-color.jpg` | メニュー「韓国カット＋カラー」 | カット・カラーのイメージ |
| `menu-hairset.jpg` | メニュー「15分ヘアセット」 | ヘアセットのイメージ |
| `menu-makeup.jpg` | メニュー「黄金比フルメイク」 | メイクのイメージ |
| `menu-nail.jpg` | メニュー「ロングネイル」 | ネイルのイメージ |
| `menu-jewelry.jpg` | メニュー「Body & Eye Jewelry」 | ジュエリー装飾のイメージ |

画像が用意されるまでは、サイト上に「仮画像」バッジと説明文つきのプレースホルダーが表示されます。
掲載するメニュー写真・内容・料金はすべて提案用の仮表示であり、実際のメニューとは異なる場合があります。

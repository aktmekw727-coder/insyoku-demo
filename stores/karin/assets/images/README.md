# 画像ファイルについて（旬彩 佳鈴 デモ）

写真はまだ確定していないため、現時点ではこのフォルダに画像を配置していません。
サイト側は下記のファイル名を参照する実装になっているため、実際の写真が決まったら
同じファイル名でこのフォルダに配置するだけで、仮画像プレースホルダーから自動的に
実写に切り替わります（サイトの他の修正は不要です）。

推奨形式: JPG / 横長カットは 4:3〜16:9 目安。

| ファイル名 | 用途 | 内容の目安 |
|---|---|---|
| `hero.jpg` | トップ ヒーロー背景 | 店内・料理の雰囲気が伝わるカット |
| `interior.jpg` | 店舗情報セクション | 店内（カウンター等）の雰囲気 |
| `course-3000.jpg` | おまかせコース ライト（¥3,000） | コースの一例 |
| `course-4000.jpg` | おまかせコース スタンダード（¥4,000） | コースの一例 |
| `course-5000.jpg` | おまかせコース プレミアム（¥5,000） | コースの一例 |

画像が用意されるまでは、サイト上に「仮画像」バッジと説明文つきのプレースホルダーが表示されます。

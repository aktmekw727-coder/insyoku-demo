# 焼肉 陣力 — 営業デモWebサイト（鹿児島県鹿屋市）

実店舗「焼肉 陣力」をベースにした営業用デモWebサイトです。
本番運用は想定しておらず、ログイン・DB・外部API接続は一切なし、すべてダミーデータと条件分岐だけで動作します。

デザインは白・生成り・木目をベースに、黒とえんじ（深い赤）をアクセント、金は見出し・ロゴなど最小限に留め、
「明るく清潔感があり、家族・子供連れでも入りやすい地元の焼肉店」という実店舗の雰囲気を大切にしています。

## 起動方法

ビルド不要の静的サイトです。`index.html` / `style.css` / `script.js` / `assets/` をそのまま配信できます。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセスしてください。

## ファイル構成

```
insyoku-demo/
├── index.html
├── style.css
├── script.js
├── assets/images/
└── README.md
```

- 外部ライブラリ・フレームワークなし
- メニュー・おすすめ・診断ロジックは `script.js` に集約
- 写真は `assets/images/` の固定ファイル名で参照

## 営業デモで見せるポイント

1. ホーム：店の雰囲気とメニューカテゴリ
2. メニュー：カテゴリのタブ切替
3. おすすめ：代表メニューの写真付きカード
4. おすすめ診断：人数・気分・予算から組み合わせを提案
5. 店舗情報：店内・アクセス・LINE導線など
6. 本格導入時に追加できる予約管理・来店スタンプ・顧客管理など

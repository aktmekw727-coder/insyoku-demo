# 画像の差し替えについて

このフォルダに以下のファイル名で写真を置くと、サイト側のコード変更なしに自動で反映されます。
ファイルが無い状態でもレイアウトは崩れず、代わりに木目調のプレースホルダー（写真名のラベル入り）が表示されます。

推奨形式: JPG または WebP / 横長カットは 4:3〜16:9、正方形カットは 1:1 目安。

| ファイル名 | 用途 | 内容の目安 |
|---|---|---|
| `hero-yakiniku.jpg` | トップ ヒーロー背景 | 網の上で肉を焼いている様子 |
| `jinriki-sign.jpg` | ヒーロー内サブビジュアル | 木製「陣力」看板・店舗入口 |
| `interior.jpg` | 店舗情報セクション | 明るい店内（座敷・カウンター） |
| `karubi.jpg` | おすすめ／焼肉メニューカテゴリ | 陣力カルビ |
| `tokusen-karubi.jpg` | おすすめ | 特選カルビ |
| `tongue.jpg` | おすすめ | 上タン塩 |
| `harami.jpg` | おすすめ | ハラミ |
| `kurobuta.jpg` | おすすめ | 黒豚バラ焼 |
| `family-set.jpg` | おすすめ／盛り合わせ・セットカテゴリ | ファミリーセット |
| `bara-don.jpg` | おすすめ／ランチメニューカテゴリ | 鹿屋黒豚ばら丼 |
| `ippin.jpg` | 一品料理・ご飯・麺カテゴリ | 一品料理やご飯・麺の代表カット |
| `kids-menu.jpg` | お子様メニューカテゴリ | お子様メニュー・ファミリー利用の様子 |

合計12枚あれば全箇所が実写真になります。一部だけ差し替えても、残りは自動でプレースホルダーのままなのでレイアウトは壊れません。

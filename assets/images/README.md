# 画像ファイルについて

営業デモで使用する画像はこのフォルダに配置しています。サイト側は以下のファイル名を参照します。

推奨形式: JPG / 横長カットは 4:3〜16:9、正方形カットは 1:1 目安。

| ファイル名 | 用途 | 内容の目安 |
|---|---|---|
| `hero-yakiniku.jpg` | トップ ヒーロー背景 | 網の上で肉を焼いている様子 |
| `jinriki-sign.jpg` | ヒーロー内サブビジュアル | 店舗入口・木部のディテール |
| `interior.jpg` | 店舗情報セクション | 店内の雰囲気 |
| `karubi.jpg` | おすすめ／焼肉メニューカテゴリ | 陣力カルビ |
| `tokusen-karubi.jpg` | おすすめ | 特選カルビ |
| `tongue.jpg` | おすすめ | 上タン塩 |
| `harami.jpg` | おすすめ | ハラミ |
| `family-set.jpg` | おすすめ／盛り合わせ・セットカテゴリ | ファミリーセット |
| `bara-don.jpg` | おすすめ／ランチメニューカテゴリ | 鹿屋黒豚ばら丼 |
| `ippin.jpg` | 一品料理・ご飯・麺カテゴリ | 一品料理やご飯・麺の代表カット |
